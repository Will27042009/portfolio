Portfólio

Este foi o primeiro site que desenvolvi estudando front-end, construído do zero em HTML e CSS. O objetivo foi praticar estruturação semântica de página, organização de layout com Flexbox e Grid, e estilização responsiva — da barra de navegação ao formulário de contato. Um dos principais desafios foi organizar o layout para funcionar bem tanto no computador quanto no celular, o que me fez estudar mais a fundo como o CSS Grid se comporta em diferentes tamanhos de tela.
